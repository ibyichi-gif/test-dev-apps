# 🏐 小学生バレーボール 陣形・ポジション 設計書 v3.0

**対象**: 小学生6人制バレーボール(ローテーションなし・フリーポジション制)
**準拠ルール**: 一般社団法人 日本小学生バレーボール連盟「小学生バレーボール競技規則」(2025-2026年度)
**用途**: 指導資料・クイズアプリ・動画教材などで共通利用可能な陣形定義

## 📐 1. コート仕様(日小連公式)

| 項目 | 仕様 |
|---|---|
| コートサイズ | **16m × 8m** |
| ネット高 | 2.00m(男女共通) |
| アタックライン | センターラインから **2.7m**(一般の3mより短い) |
| サービスゾーン | エンドラインの後方、8m幅 |
| ボール | 軽量4号球(円周62-64cm、200-220g) |
| リベロ | **非適用** |
| ローテーション | **なし**(フリーポジション制) |
| バックアタック | **制限なし**(アタックヒット反則適用せず) |
| サーブのダイレクトアタック | **禁止**(ネット上端より高くフロントゾーン内のボール) |
| 得点 | 21点制、2セット先取、第3セット15点 |
| 選手交代 | 1セット12回まで |

### コート座標系(アプリ内部、0〜100)

```
   x=0 ─────────────────────── x=100
    │                                  │   y=0    相手エンドライン
    │     相手バックゾーン               │
    │                                  │
    ├ ─ ─ ─ ─ ─ アタックライン ─ ─ ─ ─ ─┤   y=25
    │     相手フロントゾーン              │
    │                                  │
    ━━━━━━━━━━━━━━━━━━━━ ネット ━━━━━━━━   y=50
    │                                  │
    │     自フロントゾーン               │
    ├ ─ ─ ─ ─ ─ アタックライン ─ ─ ─ ─ ─┤   y=75
    │                                  │
    │     自バックゾーン                 │
    │                                  │
    ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   y=100 自エンドライン
```

実寸換算:
- y=0〜100 は 縦16m を表す(1単位 = 16cm)
- x=0〜100 は 横8m を表す(1単位 = 8cm)
- アスペクト比は **縦:横 = 2:1**(コート描画時に維持)

## 👥 2. 6ポジション モデル(役割ベース)

小学生バレーでは、**役割ベースの6ポジション**で構成。従来の「前衛3×後衛3」の6ゾーン固定ではなく、各選手に固定の役割を持たせる。

### 6ポジションの役割

| 記号 | 役割名 | 主な仕事 |
|:-:|---|---|
| **L** | レフト(レフトスパイカー) | 前衛でアタック、レシーブ参加 |
| **C** | センター | 前後に動くセンター選手。ブロック・速攻・レシーブ |
| **R** | ライト(ライトスパイカー) | 前衛でアタック、レシーブ参加 |
| **S** | セッター | ネット際独立、トスを上げる役。背が高ければブロッカー兼任 |
| **LB** | レフトバック | 後衛レシーバー、コート左後方を守る |
| **RB** | ライトバック | 後衛レシーバー、コート右後方を守る |

### 重要ポイント

1. **Sはネット際に独立**しており、W型陣形の「5人」には含まれない(W字はL/R/C/LB/RBの5人で描く)
2. **Cは1人**しかいない。局面によって前にも後ろにも行く
3. **CとSの役割が入れ替わる場面がある**(Dig時、背が高いほうがブロッカー真ん中=MB役)

## 🏐 3. 陣形パターン(全11種類)

### 🅰️ W型 レセプション(`w-type`)

**用途**: サーブレシーブの基本形
**特徴**: L・C・R が前衛(LとRがやや左右に開く)、LB/RB が後衛中央寄り、Sはネット際独立

| 選手 | 座標 |
|:-:|:-:|
| L | **(18, 70)** |
| C | **(50, 72)** |
| R | **(82, 70)** |
| S | **(70, 58)** |
| LB | **(30, 85)** |
| RB | **(70, 85)** |

**メリット**: 1人あたりの守備範囲が狭く、初心者向き
**デメリット**: 5人全員がレセプションに入るため攻撃への移行が遅い

### 🅱️ 逆W型 レセプション(`reverse-w`)

**用途**: 相手サーバーが**奥を狙う**場合、後方3人が動かずにレシーブできるよう配置
**特徴**: L/Rが前衛(中央寄り・後ろ寄り)、LB/C/RBが横3枚で後衛

| 選手 | 座標 |
|:-:|:-:|
| L | **(30, 72)** |
| R | **(70, 72)** |
| S | **(70, 58)** |
| LB | **(18, 85)** |
| C | **(50, 85)** |
| RB | **(82, 85)** |

**メリット**: コート奥をしっかり守れる、サーブが深い時に強い
**デメリット**: ネット際の短サーブは前衛2人に負担集中

### 🛡️ Dig 陣形(6パターン)

**基本原則**:
- **ブロック2枚がアタッカーの正面に並ぶ**(L/R打ちの時)
- **Cクイック時はブロック1枚(MB役のみ)**、L/Rは両サイドでフェイント対応
- **背が高いほう**(SかC)が前衛真ん中 = MB役になる
- **Cが前衛ブロッカー**の時、Sは後衛RB位置に下がる(RBは中央寄りでカバー)

#### Ⓒ-1 Dig・相手L打ち・S背高(`dig-L-tallS`)

相手L アタッカー(x≈18) 正面に味方 L + S でブロック2枚。

| 選手 | 座標 | 役割 |
|:-:|:-:|---|
| L | **(15, 55)** | ブロッカー(ストレート) |
| S | **(32, 55)** | ブロッカー(MB役・クロス) |
| R | **(78, 65)** | 逆サイドでフェイント対応 |
| LB | **(20, 82)** | 後衛 |
| C | **(50, 82)** | 後衛 |
| RB | **(80, 82)** | 後衛 |

#### Ⓒ-2 Dig・相手L打ち・C背高(`dig-L-tallC`)

C が MB役、Sは後衛RB位置に下がる。

| 選手 | 座標 | 役割 |
|:-:|:-:|---|
| L | **(15, 55)** | ブロッカー(ストレート) |
| C | **(32, 55)** | ブロッカー(MB役・クロス) |
| R | **(78, 65)** | フォロー |
| LB | **(20, 82)** | 後衛 |
| RB | **(55, 82)** | 中央寄り(Sがいた場所カバー) |
| S | **(80, 82)** | RB位置に下がる |

#### Ⓒ-3 Dig・相手R打ち・S背高(`dig-R-tallS`)

相手R アタッカー(x≈82) 正面に味方 R + S でブロック2枚。

| 選手 | 座標 | 役割 |
|:-:|:-:|---|
| L | **(22, 65)** | 逆サイドフォロー |
| S | **(68, 55)** | ブロッカー(MB役) |
| R | **(85, 55)** | ブロッカー(ストレート) |
| LB | **(20, 82)** | 後衛 |
| C | **(50, 82)** | 後衛 |
| RB | **(80, 82)** | 後衛 |

#### Ⓒ-4 Dig・相手R打ち・C背高(`dig-R-tallC`)

| 選手 | 座標 | 役割 |
|:-:|:-:|---|
| L | **(22, 65)** | フォロー |
| C | **(68, 55)** | ブロッカー(MB役) |
| R | **(85, 55)** | ブロッカー(ストレート) |
| LB | **(20, 82)** | 後衛 |
| RB | **(55, 82)** | 中央寄り |
| S | **(80, 82)** | RB位置 |

#### Ⓒ-5 Dig・相手Cクイック・S背高(`dig-C-tallS`)

Cクイックは1枚ブロック(MB役のS)、L/R両サイドでフェイントカバー。

| 選手 | 座標 | 役割 |
|:-:|:-:|---|
| S | **(50, 55)** | ブロッカー1枚(MB役) |
| L | **(18, 65)** | 左サイドフェイント |
| R | **(82, 65)** | 右サイドフェイント |
| LB | **(20, 82)** | 後衛 |
| C | **(50, 82)** | 後衛 |
| RB | **(80, 82)** | 後衛 |

#### Ⓒ-6 Dig・相手Cクイック・C背高(`dig-C-tallC`)

| 選手 | 座標 | 役割 |
|:-:|:-:|---|
| C | **(50, 55)** | ブロッカー1枚(MB役) |
| L | **(18, 65)** | 左サイドフェイント |
| R | **(82, 65)** | 右サイドフェイント |
| LB | **(20, 82)** | 後衛 |
| RB | **(55, 82)** | 中央寄り |
| S | **(80, 82)** | RB位置 |

### ⚔️ 攻撃陣形(2パターン)

#### Ⓓ 攻撃・LRのみ(`attack-lr`)

**用途**: LとRがアタッカー、Cはレシーブ専念(攻撃できない/背が低いC)

| 選手 | 座標 | 役割 |
|:-:|:-:|---|
| L | **(12, 72)** | 助走開始(コート外寄り) |
| C | **(50, 73)** | 前衛中央でレシーブ/カバー |
| R | **(88, 72)** | 助走開始(コート外寄り) |
| S | **(70, 58)** | トス準備(ネット際) |
| LB | **(25, 85)** | 後衛 |
| RB | **(75, 85)** | 後衛 |

#### Ⓔ 攻撃・LRC全員(`attack-lrc`)

| 選手 | 座標 | 役割 |

| S | **(70, 58)** | トス準備 |
| LB | **(30, 87)** | 後衛 |
| RB | **(70, 87)** | 後衛 |

## 🎯 4. 陣形の選び方(シーン別)

| シーン | 推奨陣形 | 選択根拠 |
|---|---|---|
| サーブが来る(普通) | `w-type` | 全員均等に守備範囲 |
| サーブが来る(奥狙い/エース) | `reverse-w` | 後方3枚で深いサーブに対応 |
| 相手Lアタック(Sが高い) | `dig-L-tallS` | LとSがブロック、Rフォロー |
| 相手Lアタック(Cが高い) | `dig-L-tallC` | LとCがブロック、SがRBへ |
| 相手Rアタック(Sが高い) | `dig-R-tallS` | RとSがブロック、Lフォロー |
| 相手Rアタック(Cが高い) | `dig-R-tallC` | RとCがブロック、SがRBへ |
| 相手Cクイック(Sが高い) | `dig-C-tallS` | Sが1枚ブロック、LR両サイドカバー |
| 相手Cクイック(Cが高い) | `dig-C-tallC` | Cが1枚ブロック、SがRBへ |
| 味方アタック(L/Rのみ打てる) | `attack-lr` | Cはレシーブ/カバー、LRが主攻撃 |
| 味方アタック(全員打てる) | `attack-lrc` | 3枚攻撃でコンビネーション |
| 構え中・移行中 | `neutral` | 攻守どちらにも対応 |

## 🎨 5. 描画表現ルール(図解用)

### 5.1 矢印の色と意味

| 色 | 意味 | 線種 |
|---|---|---|
| **オレンジ** (#ff5a1f) | スパイク・強いボールのコース | 実線 + 矢じり |
| **黄色** (#ffd447) | パス・トスの軌道(味方の連携) | 実線 + 矢じり |
| **青** (#3b82f6) | 選手の移動・助走 | 破線 + 矢じり |
| **赤** (#ef4444) | 禁止・悪い例・ミス | 破線 |
| **白** (#ffffff) | 視線・中立の予測 | 点線 |

### 5.2 ヒートマップ(狙いの色濃淡)

| 濃度 | 色 | 意味 |
|---|---|---|
| 濃(0.7以上) | オレンジ濃 | 最も狙うべき場所/最も弱いコース |
| 中(0.4〜0.7) | 黄色 | 次善の選択肢 |
| 薄(0.4未満) | 灰色薄 | 避けるべき場所/無効 |

### 5.3 選手の表示スタイル

| 状態 | 表現 |
|---|---|
| 問題の主役(注目) | 黄色の円、パルスアニメ、大きめ |
| 苦手・疲れ(weak) | 赤い輪郭の点滅、小さめ |
| 相手(them) | 灰色の円 |
| 味方(us、通常) | 白の円 |
| セッター(S) | 黄色の円 |
| 自動補完(背景役) | 不透明度0.35で薄く表示 |

## 📋 6. 実装上の運用ルール

### 6.1 問題データの指定方法

```javascript
court: {
  formation: 'w-type',        // 陣形を指定(11種類から選択)
  players: [                  // 明示したい選手のみ記述
    {team:'us', pos:[30, 85], role:'LB', highlight:true},  // 主役
    {team:'them', pos:[50, -30], role:'S'}                  // 相手サーバー
  ],
  ball: [50, 25],              // ボールの位置(任意)
  arrows: [...],               // 矢印(任意)
  heatZones: [...]             // ヒートマップ(任意)
}
```

- **明示しない選手**は `formation` に従って自動補完される(opacity=0.35で薄く)
- `formation` 文字列指定、または `{us: 'xxx', them: 'yyy'}` でチーム別指定可
- `noAutoFill: true` で自動補完を完全無効化

### 6.2 形式ルール

| 項目 | ルール |
|---|---|
| 役割名 | `L` / `C` / `R` / `S` / `LB` / `RB` (新表記) |
| 旧表記(LF/MF/RF/MB) | 自動で L/C/R/C に変換される(`ROLE_ALIASES`) |
| 座標系 | x,y ともに 0〜100、y<0またはy>100はコート外 |
| y座標基準 | y=0 相手エンドライン / y=50 ネット / y=100 自エンドライン |
| Sのデフォルト | y=58(ネット際、自コート側)、攻撃時もこの位置 |
| 前衛y | 55(Digブロック)〜70-72(通常)〜73(攻撃時LRフォロー) |
| 後衛y | 82(Dig)〜85(通常・攻撃)〜87(攻撃時LRC) |
| コート外 | y<0(相手サーブ位置)、y>100(自サーブ位置) |

### 6.3 them(相手)側の座標

them側の陣形は us 側の **y座標を 100 - y で鏡像反転** (x はそのまま)。
FORMATIONS定数に them: {...} として同じ11陣形分を定義済み。

## 📝 8. 更新履歴

- **v1.0**: LF/MF/RF/LB/MB/RB の6ゾーンモデル(一般的な6人制の流用、小学生不適切と判明)
- **v2.0**: L/C/R/S/LB/RBの6ポジション役割モデルに転換。W型/逆W型/Dig(身長タイプ別2種)/攻撃(LR・LRC)/中立の7陣形を定義。
